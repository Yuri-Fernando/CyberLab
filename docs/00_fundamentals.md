# Fundamentos: GAN não é Adversarial ML

Uma GAN é uma arquitetura generativa treinada por competição entre gerador e discriminador. Adversarial ML é o campo de segurança que estuda manipulações deliberadas do pipeline de ML, incluindo poisoning, evasion, extraction e violações de privacidade.

O termo “adversarial” aparece nos dois contextos, mas o threat model, os ativos e as métricas são diferentes.
